# Mejora de Experiencia de Usuario en eCommerce mediante Animaciones y Transiciones

El equipo de eCommerce de una empresa de retail necesita mejorar la experiencia de usuario en su plataforma VTEX. El objetivo es aplicar conscientemente conceptos de animaciones y transiciones orientadas a microinteracciones, alineadas con la UX definida en el proyecto. El sistema debe permitir a los usuarios interactuar con productos, añadirlos al carrito y realizar la compra de manera fluida y atractiva.
